# Decisões Arquiteturais

## Objetivo

Esta pasta registra as principais decisões técnicas e arquiteturais do projeto por meio de ADRs (Architecture Decision Records).

Cada ADR documenta uma decisão, suas alternativas, motivações e consequências.
